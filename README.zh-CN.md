# Research Navigator 研究导航

**一份给硕士、博士生用的“导师式”提示词。** 复制到任何 AI 对话里就能用。它帮你规划课题、审阅草稿、搭建文献综述、写作前先理清段落逻辑，并专门检查最容易让学生白费几个月的错误。

[English](README.md) · [Español](README.es.md)

## 一分钟开始（不需要写代码）

1. 打开 **[WEB-START.txt](WEB-START.txt)**（[纯文本，方便全选复制](https://raw.githubusercontent.com/Zack0303/research-navigator/main/WEB-START.txt)）。
2. 把全文复制到 ChatGPT、Claude、Gemini、DeepSeek、Kimi 等的新对话里；支持附件也可直接上传。只发链接不行。
3. 用你熟悉的语言说需求，例如：

> 我是教育学硕士，想研究老师怎么用 AI 批改工具，但题目太大。我有四个月时间。请用中文解释，最终用英语提交。

你应该得到：两三个关键问题、一个暂定方向、一个明确的下一步。没有学校要求也能开始，不知道的规则会标成“未知”。

## 和直接问 AI 有什么不同

普通 AI 已经能看出明显问题，比如没有方法、训练和测试用了同一批数据。Research Navigator 另外加了 **六项检查**，专门找那些“每一步看起来都合理”所以容易漏掉的问题：

| 检查 | 它问的问题 |
|---|---|
| **C1 锚点** | 课题是否已经偏离你和导师真正需要的问题？ |
| **C2 最近邻** | 最接近的 3–5 篇工作已经做了什么？你真正新增的是什么？ |
| **C3 主张强度** | 有没有哪句话说得比证据更强？ |
| **C4 评价尺子** | 是按每篇研究自己的目标来评价，还是用了一把不合适的统一“阶梯”？ |
| **C5 小试估工作量** | 工作量是用小规模试做量出来的，还是拍脑袋猜的？ |
| **C6 未知不等于零** | 每条规则、数字和状态都有出处吗？“计划做”和“已做完”分开了吗？ |

这些检查来自写一篇系统文献综述时踩过的真实坑：
- 每一步收窄看起来都合理，结果一路偏离了课题组的目标；
- 用一把统一的“价值阶梯”去评价所有研究，拿它们本来就没打算做的事来扣分；
- 差点把别的综述早就用过的分类方式当成自己的创新。

它还给出简短、统一、可以直接分享的输出：
- **一页研究简报**：尽早拿给导师看；
- **审阅报告**：一句话结论、最多五个优先问题、主张强度表和下一步；
- **文献综述搭建表**：附带基于小试的工作量估计；
- **段落简报**：写之前先定好每段的主张、证据和不能说的话，逻辑是你自己的。

## 试试这些

**有想法 → 做计划**
> 我是运营管理博士生，对用大语言模型做生产排程感兴趣。帮我找一个能做完的第一项研究。用中文解释，提交语言是英语。

**审阅草稿**
> 审阅我 proposal 里的这段话：“本研究将证明 AI 能降低库存成本 30%。我会用全部数据训练和测试模型。以前没人研究过这个问题。”我还没有学校要求。

**文献综述**
> 我的硕士论文需要做一个关于医院数字孪生的系统文献综述，我有十周时间，从哪里开始？

**写作前规划一节**
> 帮我在动笔前规划论文的 Discussion 部分。主要发现是新方法更快，但不更准。

## 它不会做的事

- 编造论文、引用、页码、数字或学校规则；
- 没有在本次对话中真正读过来源时，说“已核实”；
- 在学校 AI 政策未知或禁止时，替你写可直接提交的文字（会改为给结构和反馈）；
- 没检索就声称“前人没研究过”。

请先用公开或虚构的材料试用，不要粘贴雇主的机密信息。用于考核作业前，先确认学校的 AI 使用规定。

## Agent 用户（Codex、Claude Code 等）

在 Agent 里打开本文件夹，说：`请读取 SKILL.md，按 Research Navigator 指导我。` 然后描述任务。参见 [Codex 逐步入门](docs/start-in-codex.md)。Agent 版会读取更详细的[检查说明](references/checks.md)、[输出模板](references/templates.md)和[文献综述指南](references/lit-review.md)。

进阶功能：根据学者公开发表的研究，整理有出处的方法笔记。[学者指南](references/scholar-generator.md) · [示例](examples/scholar-bengio-selected-methods/SKILL.md)
