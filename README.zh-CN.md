# Research Navigator 研究计划助手
帮助硕士、博士学生把宽泛想法变成可执行的研究计划，或根据有出处的学校要求审阅草稿。

[English](README.md) · [Español](README.es.md)


## 🌐 直接在网页 AI 里用：新手从这里开始
**不需要工科背景，不需要安装 Codex，不需要写代码。**

1. 打开 **[网页 AI 使用包](WEB-START.txt)**，把全文复制到 Gemini、DeepSeek 或其他 AI 的新对话中。如果支持文本附件，也可以上传该文件。不要只发送文件链接。
2. 用你熟悉的语言说需求。例如：**“我是历史学硕士，想研究地方报纸，但题目还很宽泛。请用中文帮我缩小范围，最终提交语言是英语。”**

AI 应先问少量关键问题，再带你往下做。没有学校链接、没有完整草稿也能开始。不能联网时，学校要求会保持“待核实”；不能生成文件时，学者方法会以可复制文字交付。不同网页的附件与联网能力不同，目前尚未逐一实测兼容性。

## 另一种方式：在 Codex 等 Agent 中打开本地文件夹

[Codex 逐步入门](docs/start-in-codex.md)
需要能够读取本地文件的 AI Agent。在线核验学校和学者来源还需要联网浏览；生成文件需要文件写入能力；进阶离线生成器需要 Python，详见进阶说明。这里提供的是给 Agent 使用的指令，不是独立聊天软件；Agent 平台可能收取通常的使用费用。

1. 下载并解压整个仓库，或使用已有本地副本。
2. 在 Agent 中打开 `research-navigator` 文件夹，保留 SKILL.md 和旁边的参考目录。
3. 复制下面任一段话。它会明确让 Agent 读取指令，无需先配置自动安装。

若你的工具无法打开文件夹或读取本地文件，这条路径暂不适用。不同平台的自动安装方式尚未在本项目验证。

### 我只有一个想法
```text
请读取当前工作区的 SKILL.md，按 Research Navigator 指导我。
我是运营管理硕士，有八周时间，想用模拟数据研究需求预测。用中文解释，提交语言是英语。我没有学校要求链接。先问最关键的问题，帮我缩小研究范围，并标出待核实要求。
```

### 帮我审阅草稿
```text
请读取当前工作区的 SKILL.md，按 Research Navigator 审阅这段模拟草稿：
“AI 将降低库存成本 30%。我会用全部数据训练并测试。以前没人研究过这个问题。”
用中文说明。尚无学校要求，请区分方法建议和待核实规则，给出三个优先行动，不要编造文献。
```

### 生成学者方法 Skill
```text
请读取当前工作区的 SKILL.md，按 Research Navigator 帮我制作可复用的学者方法 Skill。
学者：Yoshua Bengio，Université de Montréal。关注机器学习方法比较。只使用公开学术证据，每个观察给出处，应用建议标为解释。先确认能否浏览和写文件；不能时说明下一步。不要冒充学者本人。
```

首次规划应得到：少量关键问题、暂定研究方向、已知与未知要求表、下一步行动。没有学校链接也可以先开始。

指导语言与提交语言独立，可请求任意语言；中英西语尚未全面验证。先用公开或模拟内容体验，不要加入雇主机密；提交相关使用应遵守学校 AI 规则。
