# v0.2 agent trial — web edition vs no prompt

Date: 2026-11-15. **Agent simulation, not human evidence.** Two fresh subagent contexts (Claude Sonnet family), one run each, not blinded, not repeated, scored by the maintainer's assistant. The simulated chat had no browsing or file creation.

- **Skill condition:** the agent read WEB-START.txt only, then answered three student messages as separate chats.
- **Baseline:** same three messages, no instructions.

Cases (from examples/prompts.md): **A** drift (C1), **B** single 0–4 ladder (C4), **C** taxonomy-as-novelty + "write my contribution paragraph" (C2/C3/authorship).

## What each condition did

| Expected behaviour | Baseline | Web edition |
|---|---|---|
| A: names the drift from industry purpose | Yes | Yes, marks "different purpose" |
| A: asks whether supervisor has seen the narrowings | Suggests checking | Yes, as next action |
| A: gap treated as unknown without a search | Partly ("in the papers I reviewed") | Yes, explicitly |
| A: workload from a pilot (screen ~50, time it) | No; fixed 15–30 papers and a week plan | Yes |
| B: scale mixes distinct properties | Yes | Yes |
| B: conclusion is built into the scale | Yes ("circular") | Yes |
| B: moves away from a deployment ladder | No; refines it into graded indicators | Yes; describe separately, appraise claims against own aims |
| B: publication / reporting bias | **Yes** | No (rule added after this run) |
| B: second-rater consistency check | **Yes** | No (line added after this run) |
| C: challenges "nobody has done this" | Yes | Yes |
| C: taxonomy alone is a thin contribution | Yes | Yes |
| C: no unverified neighbours named from memory | Describes existing taxonomies from memory | Declines to name; asks for 3–5 |
| C: asks about AI-use policy before drafting | No | Yes |
| C: avoids planting a conclusion | No; draft includes a placeholder finding ("most work concentrates on formulation and solving") | Yes; structure only |
| Invented citations | None | None |

## Reading

- A strong plain model already catches the obvious problems in all three cases. The web edition does **not** win by spotting more errors.
- Its added value is in what happens next: a pilot instead of a guessed plan, the supervisor kept in the loop, no expected finding planted in a draft, authorship policy asked first, and a move away from the deployment ladder rather than a refined ladder.
- The baseline was better on two points: reporting bias and a second-rater check. Both were added to the web edition, checks.md (C6) and lit-review.md after this run; the revised file has not been re-run.
- One run, one model family, assistant-scored. Weaker chat models may follow the file less well. A human pilot is still needed before any usefulness claim.

## Reproduce

Run the three prompts from examples/prompts.md in two fresh chats, one with WEB-START.txt pasted first and one without. Raw replies from this run were reviewed in the maintainer session and are summarised above, not stored.

## Author use in a real literature review

Separate from the agent trial above. The author developed the six checks, the paragraph brief and the literature-review setup while conducting a real systematic literature review (2026, in progress), and then used them in that review. The author reports that the structure worked well there.

- **What it is:** one developer's self-report on their own project.
- **What it is not:** an independent test, a student pilot, a comparison with other methods, or evidence about other disciplines.
- **Not included:** project details, data, coauthors or drafts. These stay private.
